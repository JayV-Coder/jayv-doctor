# Guia do usuário

O Integration AI Doctor acompanha as integrações entre SAP, Salesforce e GCP. Ele agrupa as falhas em **Incidentes** e propõe um **Diagnóstico**: a causa provável, as Evidências que a sustentam e as Recomendações. **A decisão é sempre de uma pessoa:** o Doctor não altera nenhum sistema do cliente.

1. [Primeiros passos](primeiros-passos.md): conta, Organização, membros e a primeira Integração.
2. [Conector GCP](conector-gcp.md): coleta automática do Cloud Logging.
3. [Importação de logs](importacao.md): arquivos de histórico e ambientes sem Conector.
4. [Lendo um Diagnóstico](diagnostico.md): Evidências, Confiança, revisão e Relatório técnico.

O app é um PWA pensado primeiro para o celular. No computador, as telas de Incidente e Dashboard mostram mais colunas.
